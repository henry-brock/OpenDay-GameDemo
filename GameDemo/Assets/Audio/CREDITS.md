# Music Credits

All music in this project is used under the **Creative Commons Attribution
4.0 International licence (CC BY 4.0)**:
<https://creativecommons.org/licenses/by/4.0/>

CC BY 4.0 requires, for every track: the creator's name, the track title, a
link to the source, a link to the licence, and whether the track was
changed from its original form. Fill in one entry per file as tracks are
added to `Assets/Audio/<SceneName>/` — this file should always list exactly
the files actually present, no more, no less.

This file is also the source for an in-game credits screen if one gets
built later, and for the "Legal Considerations" section of the write-up —
keep it accurate as you go rather than reconstructing it at the end.
